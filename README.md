# Bike-Store-Sales-Inventory-Analysis
This project is a relational database and SQL analysis exercise based on a Bike Store business model. 

## Project Overview
This project is a relational database and SQL analysis exercise based on a Bike Store business model.  
It includes table creation, CSV data import, and SQL queries for store performance, product popularity, customer location, brand insights, and stock alerts.

## Objectives
- Create a structured Bike Store database.
- Import CSV files into MySQL.
- Analyze sales, customers, products, brands, and stock data.
- Practice SQL joins, grouping, sorting, and aggregation.

## Tools Used
- MySQL
- MySQL Workbench
- Kaggle Bike Store sample data
- CSV import using `LOAD DATA LOCAL INFILE`

## Database Tables
The project includes the following tables:

### Core Tables
- `stores`
- `customers`
- `brands`
- `categories`
- `products`
- `staffs`
- `orders`
- `order_items`
- `stocks`

## Table Relationships
- `customers` place `orders`
- `orders` belong to `stores`
- `orders` contain `order_items`
- `order_items` reference `products`
- `products` belong to `brands` and `categories`
- `stocks` track product quantity by store
- `staffs` are assigned to stores

## Project Tasks
### 1. Store Performance
Calculate total revenue generated by each store.

### 2. Product Popularity
Find the top 5 most sold products by quantity.

### 3. Customer Location
List customers who placed orders along with the store names.

### 4. Brand Insights
Find the total number of products per brand.

### 5. Low Stock Alert
Identify products with zero quantity in stock.

## Sample Workflow
1. Create the database and tables.
2. Import all CSV files into the matching tables.
3. Run the SQL analysis queries.
4. Review the results for business insights.

## CSV Import Notes
- Use `LOAD DATA LOCAL INFILE` in MySQL.
- Make sure `local_infile` is enabled on both client and server.
- Import files in the correct order:
  1. `stores`
  2. `customers`
  3. `brands`
  4. `categories`
  5. `products`
  6. `staffs`
  7. `orders`
  8. `order_items`
  9. `stocks`

## Key Learnings
- Designing relational tables.
- Creating primary keys.
- Loading CSV data into MySQL.
- Writing SQL joins across multiple tables.
- Using `GROUP BY`, `ORDER BY`, `SUM`, `COUNT`, and `LIMIT`.

## Conclusion
This project demonstrates how SQL can be used to organize retail data and generate useful business insights from a Bike Store dataset.
